## 2. Residual Epistemic Limits (Honest Boundary Statement)

Even after remediating all 14 findings, `endo.coordinator-grounded-brief.v1` does **not** claim universal factual correctness or omniscience:

1. **Snapshot-relative truth only:** Grounding guarantees factual consistency with the controller's observed read-only projections at `readAtMs`. If the underlying Git working tree, background agent process, or filesystem changes after observation (or is unobserved because liveness is not probed), the snapshot can only represent what Endophasia recorded.
2. **Omission / salience selection remains model judgment:** The validator prevents false claims and unconditionally appends host completeness/truncation disclosures, but a model can still emit a *valid yet low-salience* subset of facts (e.g., citing only `head-state` and omitting a failing task). Measuring whether Inkling-2-Mini selects high-salience facts and useful priorities requires **Stage 2 paired live comparisons**.
3. **Structured JSON compliance under a small local model is unmeasured until Stage 2:** Deterministic tests prove the contract and OpenClaw `2026.11.10` bubblewrap/relay transport work end-to-end against a fake provider, but actual `Inkling-2-Mini-Uncensored-AD-Q4_K` schema-compliance and latency under `grounded-v1` are **inconclusive** until Stage 2 runs with operator authorization.
4. **Advisory standing unchanged:** Every briefing, recommendation, and proposal remains untrusted advisory interpretation granting zero operational, dispatch, route, worktree, or merge authority.

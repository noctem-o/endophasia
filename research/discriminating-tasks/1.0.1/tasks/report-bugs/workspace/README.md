# report

Turns CSV text into a totals report. `parseCsv` (src/csv.js) reads the text, `groupTotals` (src/aggregate.js) adds up amounts by key, and `renderReport` (src/report.js) prints the result.

Rules:
R1. `parseCsvLine(line)` returns the fields of one line as an array of strings. Fields are separated by commas. An unquoted field has the spaces and tabs at both ends removed. A field whose first character, after any spaces and tabs, is `"` is quoted: it runs to the closing `"`, a comma inside it is ordinary text, `""` inside it means one `"` character, and its content is kept exactly (no trimming). After the closing quote only spaces and tabs may come before the next comma or the end of the line, otherwise it throws a `SyntaxError`; a quoted field with no closing quote also throws a `SyntaxError`. An empty line gives `[""]`, and a trailing comma gives a final empty field.
R2. `parseCsv(text)` throws a `TypeError` if `text` is not a string. It splits `text` into lines at `\n` or `\r\n`, ignores lines that are completely empty, takes the first remaining line as the header, and turns each later line into an object keyed by the header fields. A line with a different number of fields than the header throws a `RangeError` whose message contains `line N`, where N is the 1-based line number in the original text, counting the empty lines too. Text with no header gives `[]`.
R3. `groupTotals(rows, keyField, valueField)` adds up `row[valueField]` for each distinct `row[keyField]`. A value must be a string of the form `12`, `-12`, `12.5` or `12.50` (at most two decimals), and a key must be a string; anything else throws a `TypeError`. The sums are exact, in whole cents, and the result is an array of `{ key, cents }`.
R4. The result of `groupTotals` is sorted by `cents` from highest to lowest, ties by `key` in plain code-unit order (the order of `<`).
R5. `renderReport(totals)` takes the result of `groupTotals` (a non-array throws a `TypeError`) and returns one string. Each entry is a line `KEY | AMOUNT`, where the key is padded on the right with spaces to the key width, and the amount is the cents written with thousands separators and exactly two decimals (`123456` is `1,234.56`, `-5` is `-0.05`), padded on the left with spaces to the amount width. After the entries comes a line of `-` characters as long as the entry lines, then a line `TOTAL | AMOUNT` laid out the same way, whose amount is the sum of all the cents. The key width is the length of the longest key, or 5 (the length of `TOTAL`) if that is larger. The amount width is the length of the widest amount, including the total's. The lines are joined with `\n` with no `\n` at the end. For an empty list the output is the dashes line and the total line only.
